- 事件时间：2026-09-02 00:45（UTC+8，页面更新时间）。
- 厂商 / 范围：阿里云 / Model Studio Long-term Memory。
- 事件摘要：官方更新长期记忆 API 参考，覆盖 `add`、`search` 等接口，并区分 Pro（启用 rerank）与 Lite（不启用 rerank）调用。

- 影响分析：对长期运行 Agent 是工程能力补齐。团队应优先评估记忆写入、召回质量、成本、删除与敏感数据留存，而非将其误解为新模型发布。
- 受影响行业 / 岗位：企业知识库、客服自动化、Agent 平台、数据治理、AI 后端。
- 来源：[阿里云 Long-term Memory API](https://help.aliyun.com/en/model-studio/long-term-memory-api-reference)
- 可信度：高。
