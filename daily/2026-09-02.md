## 速览摘要

### 国内重点

- 国内最明确的新增量来自阿里云 Model Studio 官方模型目录：9 月 1 日新增 `qwen3.7-text-rerank` 与 `qwen3.7-text-embedding-flash`，8 月 31 日纳入 `ZHIPU/GLM-5.3-Flash`，说明国产模型竞争正从“单一大模型”延伸到检索、向量、多模态整链路。
- 中文 Skills 生态继续向垂直行业与基础设施两端扩张：`oceanbase/oceanbase-skills` 代表数据库领域知识封装，`archify` 则代表高频通用图形输出。

### 全球重点

- 国际模型动态集中在三条线：Anthropic 推新一代长程 agent 模型，Google 补强视频与语音工作流，OpenAI 把安全分级和医疗数据接入公开化。
- GitHub Skills 生态的热度中心不再只是“提示词集合”，而是可验证产出、行业知识库、以及安全审计工具链。

### 行业影响

- 平台工程团队：模型切换成本正在继续下降，但 Skill 治理、上下文缓存、工具调用兼容性正在变成新的复杂度中心。
- 医疗、科研、金融等高风险行业：越来越多能力开始进入真实业务流，但“数据接入能力上线”不等于“可放开自动决策”。
- 内容与视频团队：Google 的视频理解和 Omni Flash GA 让长视频分析、编辑和生成开始形成完整流水线。

### 值得行动

- 先补三类能力：Skill 安全扫描、跨模型回归脚本、长视频/长文档 token 成本监控。
- 引入第三方 Skill 前至少核验四件事：`SKILL.md` 真伪、许可证、是否执行 shell / 网络操作、是否依赖外部账号权限。
- 如果在做 RAG 或知识工作流，建议把国产 embedding/rerank 与国际主模型拆开评测，而不是只看单模型榜单。
