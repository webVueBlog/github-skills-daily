## 速览摘要

### 国内重点

- 国内过去 7 天最确定的模型增量来自“统一云平台可调用目录”而不是单篇营销稿。阿里云官方目录在 2026-08-26 上架 `qwen3.8-flash`，在 2026-08-31 上架 `ZHIPU/GLM-5.3-Flash`，都强调长上下文、多模态和兼容 OpenAI / Anthropic 风格接入。
- 中文生态的 Skills 热点继续分化：一类是 `archify` 这类单点高频刚需 Skill，另一类是 `ai-agent-camp` 这类面向非工程岗位的课程化技能仓库。

### 全球重点

- 国际模型线最强增量来自 Google 与 Anthropic 的平台层更新。Google 在 8 月 26 日到 27 日连续把语音转写与视频生成推到 GA，Anthropic 则在 8 月 26 日到 27 日更新 SDK、Skills / Files 兼容层与合规接口。
- GitHub Skills 生态继续从“通用提示词集合”迁移到“可验证、可组合、可审计”的技能资产。微软、科研、架构图、交易、体育和安全治理方向最明显。

### 行业影响

- 研发与平台团队：更应该优先建设 Skill 版本管理、权限边界和安全审计，而不是继续堆通用 system prompt。
- 科研与医药团队：`scientific-agent-skills` 显示垂直知识工作已形成规模化技能库，但实验、医学与监管相关结论仍必须保留人工复核。
- 国内应用团队：统一 API 兼容层会进一步降低模型切换成本，回归测试矩阵要尽快覆盖国产模型与国际模型并行。

### 值得行动

- 先试三类高回报 Skill：工程质量、架构可视化、垂直行业接口。
- 把第三方 Skill 的审计前置到引入阶段，至少检查命令执行、网络访问、许可证和外部服务依赖。
- 如果你在维护多模型产品，优先为 Google Gemini、Anthropic Claude 与国产兼容 OpenAI 协议模型建立同一套验收脚本。
