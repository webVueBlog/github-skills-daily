## 速览摘要

### 国内重点

- 国内最近 7 天最有确定性的模型增量集中在云平台可用性层面，而不是单独新闻稿：阿里云官方生命周期页在 2026-08-31 列出 `ZHIPU/GLM-5.3-Flash`，在 2026-08-26 列出 `qwen3.8-flash`，说明国内开发者已经能在统一 API 平台上更快试用新一代长上下文、多模态模型。
- 中文 / 非英文 Skill 生态里，`minicoohei/ai-agent-camp` 这类“课程 + skills + commands + hooks”混合仓库升温明显，说明技能文件正从工程师专用工具走向更宽泛的培训与运营场景。

### 全球重点

- Skill 生态继续从“通用提示词合集”走向“高价值垂直能力包”：科研、游戏开发、交易、体育、架构图和安全审计是过去一周最稳定的热点方向。
- 国际模型线的最大增量不在单一跑分，而在平台层能力变化：Anthropic 发布 Files API GA 与 MHS 预览，Mistral 推基础设施合作，AWS 扩 Bedrock 上的 OpenAI 模型区域覆盖。

### 行业影响

- 研发团队：更适合优先评估工程、架构、安全和行业化 Skill，而不是继续堆通用 system prompt。
- 科研与医药：`scientific-agent-skills` 这类大规模技能库开始形成事实标准，但仍需做实验环境隔离与结果复核。
- 金融、交易与体育数据行业：`alpaca-skills`、`sports-skills` 等仓库显示“领域工具 API + 标准化 Skill”正在替代散乱脚本。

### 值得行动

- 如果你在做 Codex / Claude Code 落地，本周优先评估三类 Skill：工程质量、知识工作、垂直行业接口。
- 如果你在做国内模型接入，优先把兼容 OpenAI/Anthropic 协议的模型加入回归测试，减少供应商切换成本。
- 对任何第三方 Skill，都要额外审核权限、外部命令、网络访问、许可证与潜在 prompt injection 风险。
