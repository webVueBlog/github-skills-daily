# AI Skills & Model Intelligence Daily

每日用中文追踪 GitHub 上新近且热门的 AI Agent / Codex / Claude Code Skills，同时整理国内外大模型最新动态与热点事件。

## Skills 资讯

- 能解决什么问题
- 主要能力与典型使用方式
- 服务的行业和岗位
- 热度与新鲜度依据（Stars、近期增长、更新时间等）
- 项目链接与采用建议

## 大模型资讯

- 国内与全球新模型发布、版本升级和开源权重
- API、价格、上下文窗口、多模态和推理能力变化
- 重要评测、产品上线、合作、融资与收购
- 算力芯片、监管政策、安全事件与服务事故
- 事件影响、相关行业、可信度和可执行建议

优先采用厂商官网、官方文档、GitHub Release、论文及监管机构等一手来源。传闻和未经证实的信息不会作为事实呈现；不同口径的模型评测不会被直接混合排名。

## 日报

日报保存在 [`daily/`](daily/) 中，文件名为 `YYYY-MM-DD.md`。自动任务每天 09:00（Asia/Shanghai）更新一次；同一天重复运行时更新当天文件，不产生重复日报。

## 评选口径

优先搜索 GitHub 中与 `agent skill`、`AI skill`、`Codex skill`、`Claude Code skill`、`SKILL.md` 等相关的仓库。综合参考：

1. 最近 24 小时至 7 天的新建或更新情况；
2. Stars、Forks 及近期增长趋势；
3. 文档完整度、可安装性和真实使用价值；
4. 行业适配度及与已有条目的差异。

结果不是单纯的 Stars 排行，而是兼顾“最新、最热、可用”。
